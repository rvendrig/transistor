## DESIGN NOTES

### Color Scheme
- **Accent**: Transistor Green (#1DB954) - for buttons, highlights
- **Background**: Dark (#121212) - main background
- **Cards**: Card Dark (#1F1F1F) - content cards
- **Text**: White (#FFFFFF) - primary text
- **Gray**: (#808080) - secondary text

### Typography
- **Titles**: Bold, 18pt
- **Headers**: Semibold, 16pt
- **Body**: Regular, 14pt
- **Captions**: Regular, 12pt

### Spacing
- **Padding**: 16pt (horizontal), 12pt (vertical)
- **Corners**: 8pt border radius
- **Gap between items**: 12pt

### Interactions
- Tap program → Navigate to broadcasts
- Tap broadcast → Navigate to items
- Tap item → Show detail view
- Pull down → Refresh (Discover/Search)
- Search input → Real-time filtering
